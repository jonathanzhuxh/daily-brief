# Daily Brief · 新加坡早晚新闻与专题简报

每日早晚自动生成的新加坡本地新闻与专题简报静态站点（每天 `08:00 SGT` 早报、`20:00 SGT` 晚报，由 Antigravity 定时自动化驱动并推送更新）。

- **在线阅读**：https://jonathanzhuxh.github.io/daily-brief/
- `index.html`：最新一期简报网页（仅保留最新一期）
- `template/daily-brief-template.html`：HTML 静态页面渲染模板
- `memory/memory-log.md`：重大项目状态基线与跨期去重日志
